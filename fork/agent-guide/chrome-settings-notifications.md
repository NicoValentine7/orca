- Load merges `{...defaults.settings, ...saved}` (`M/persistence/loading-store/profile-loading/normalize-loaded-global-settings.ts:92`): a new key gets its default; flipping an existing default does not change a value the owner already saved.

Adding a setting:

1. Key in `global-settings-types.ts` (prefer optional; a required key also needs `S/settings/global-settings-test-fixture.ts`).
2. Default in `default-global-settings.ts`.
3. Migration only when flipping an existing default or renaming: `normalize-loaded-global-settings.ts`, `prepare-loaded-profile-settings.ts`, `applying-settings/default-on-migration-guards.ts`, `stripRetiredGlobalSettings`.
4. View-menu settings: `APPEARANCE_MENU_KEYS` (`settings.ts:58-63`), `AppearanceMenuState` (`register-app-menu.ts:13-19`), `getAppearanceState` (`main-process-i18n-menu.ts:91-100`).
5. Control inside a `SearchableSetting` in the pane (e.g. `AppearanceWindowSidebarSection.tsx`) plus an entry in the pane's `*-search.ts`.
6. New pane: `SETTINGS_NAV_TARGETS` (`settings/navigation/settings-navigation-types.ts:20`), a section in `settings-navigation-{interface,workflow,remote,capability}-sections.ts`, a renderer in `settings/page/settings-*-section-renderers.tsx`, call in `settings/page/settings-page-renderer.tsx:115-145`.
7. i18n per `architecture.md` (new keys must exist in every locale JSON; add `ja.json` text by hand).
8. Host-read settings also go in `S/settings/host-owned-settings.ts`.
